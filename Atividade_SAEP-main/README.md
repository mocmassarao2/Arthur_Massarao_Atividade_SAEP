# Sistema Eleitoral - CRUD em PHP e MySQL

Este é um sistema simples e funcional de **Gerenciamento Eleitoral**, desenvolvido em PHP com banco de dados MySQL via PDO. O projeto permite realizar as operações fundamentais de **CRUD** (Create, Read, Update, Delete) para **Eleitores** e **Candidatos**.

---

## 📌 Funcionalidades

- **Gerenciamento de Eleitores**:
  - Cadastrar eleitor (Nome, Número do Título de Eleitor, Cidade).
  - Listar eleitores cadastrados.
  - Editar dados de um eleitor existente.
  - Excluir registro de eleitor.
  
- **Gerenciamento de Candidatos**:
  - Cadastrar candidato (Nome, Número do Candidato, Cargo).
  - Listar candidatos cadastrados.
  - Editar dados de um candidato.
  - Excluir registro de candidato.
